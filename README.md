# ReviseAI — Student Revision Portal

Next.js 16 app for syllabus revision, AI-marked practice, lesson studio, Teams ingestion, and knowledge graph recall.

## Quick start (local, ~2 minutes)

**Prerequisites:** Node 20+, Docker Desktop (for local Postgres)

```bash
npm install
npm run setup      # env secrets + Docker Postgres + migrations + pgvector
npm run dev
```

Open [http://localhost:3000/login](http://localhost:3000/login) → **Skip for now** or create an account.

### Promote Special Admin (Teams sync, user management)

Only one SA account is allowed per deployment.

**Option A — auto (recommended for Netlify):** set in env before first signup:

```bash
BOOTSTRAP_SA_EMAIL=you@school.edu
```

**Option B — CLI** (after signing up):

```bash
npm run seed:sa -- you@school.edu
```

**Option C — Supabase SQL** (production): edit and run [`scripts/promote-sa.sql`](scripts/promote-sa.sql)

## Environment variables

Copy the template and fill in cloud keys when ready:

```bash
cp .env.example .env.local
npm run setup:secrets   # fills empty local defaults (DB URL, auth secret)
npm run setup:env       # checklist of what's set
```

| Variable | Required | Notes |
|----------|----------|-------|
| `DATABASE_URL` | Yes (online mode) | Auto-set to local Docker Postgres by `npm run setup` |
| `BETTER_AUTH_SECRET` | Yes (prod) | Auto-generated by setup |
| `NEXT_PUBLIC_APP_URL` | Yes | `http://localhost:3000` locally |
| `GOOGLE_GENERATIVE_AI_API_KEY` | For AI features | [Google AI Studio](https://aistudio.google.com/apikey) |
| `QSTASH_*` | Optional in dev | Jobs run inline without QStash locally |
| `GOOGLE_CLIENT_ID/SECRET` | Optional | Google OAuth; email/password works without |
| `NEXT_PUBLIC_SUPABASE_*` | Optional | Reserved; app uses Drizzle + `DATABASE_URL` directly |

### Supabase instead of Docker

Replace `DATABASE_URL` in `.env.local` with your Supabase **direct** connection string (Settings → Database), then:

```bash
npm run setup:db
```

Run this in the Supabase SQL editor after first migrate:

**Full bootstrap SQL:** [`scripts/supabase-sql-editor.sql`](scripts/supabase-sql-editor.sql)  
(Supabase Dashboard → **SQL** → New query → paste entire file → **Run**)

Regenerate after schema changes: `npm run db:generate && npm run db:supabase-sql`

Or run only the pgvector step if you already migrated via CLI:

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

(`npm run db:bootstrap` creates HNSW indexes automatically.)

## Scripts

| Command | Description |
|---------|-------------|
| `npm run setup` | Full local bootstrap (env + Docker + migrate + pgvector) |
| `npm run setup:secrets` | Generate `BETTER_AUTH_SECRET`, local `DATABASE_URL`, etc. |
| `npm run setup:db` | Migrate + pgvector indexes only |
| `npm run setup:env` | Show env checklist |

| `npm run db:studio` | Drizzle Studio |
| `npm run seed:sa -- email` | Promote user to Special Admin |

## Deploy to Netlify

1. Push repo to GitHub and connect in [Netlify](https://app.netlify.com).
2. **Build settings** (auto-detected from `netlify.toml`):
   - Build command: `npm run build:netlify`
   - Plugin: `@netlify/plugin-nextjs`
3. **Environment variables** (Site settings → Environment):

| Variable | Value |
|----------|--------|
| `DATABASE_URL` | Supabase **transaction pooler** URI (port **6543**) |
| `BETTER_AUTH_SECRET` | Random 32+ char secret (`openssl rand -base64 32`) |
| `NEXT_PUBLIC_APP_URL` | `https://YOUR-SITE.netlify.app` |
| `BOOTSTRAP_SA_EMAIL` | Your email — auto SA on signup |
| `GOOGLE_GENERATIVE_AI_API_KEY` | For AI features |
| `NEXT_PUBLIC_ENABLE_LOGIN_SKIP` | `false` in production |

4. **Database bootstrap** (Supabase SQL editor, once):
   - Paste and run [`scripts/supabase-sql-editor.sql`](scripts/supabase-sql-editor.sql)  
   - Or let the Netlify build run migrations if `DATABASE_URL` is set (included in `build:netlify`).

5. Deploy → open `https://YOUR-SITE.netlify.app/login` → **Sign up** with `BOOTSTRAP_SA_EMAIL`.

6. Confirm SA: Settings → Security or run in SQL:

```sql
SELECT email, role FROM users WHERE role = 'SA';
```

---

Without `DATABASE_URL`, the app runs in **offline mode** (IndexedDB + demo data).  
After setup, with a real database, skip login creates a persistent guest account in Postgres.

## Stack

- **Next.js 16** App Router · **TypeScript** · **Tailwind** · **shadcn/ui**
- **better-auth** (email + Google OAuth, roles SA/T/S/SU)
- **Drizzle ORM** + **PostgreSQL** + **pgvector**
- **Dexie.js** (local-first drafts)
- **Gemini** via Vercel AI SDK
- **Upstash QStash** (background jobs, optional in dev)
- **WebContainers** + **Pyodide** (in-browser sandboxes)
